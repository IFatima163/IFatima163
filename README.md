### ⚡ Key Research Benchmarks & Contributions

- **First Closed-Loop 3-Layer AI Framework**: Engineered a closed-loop system bridging spatial-temporal prediction, reinforcement learning dispatch, and dynamic mathematical optimization.
- **Disaster Response Layer**: Combined LightGBM + CNN-LSTM for flood prediction with Deep Deterministic Policy Gradient (DDPG) Reinforcement Learning for dynamic boat dispatch. Achieved a **0.978 ROC-AUC** and a **42.1% reduction in response latency** (18.4 min vs. 31.8–48.5 min baselines) with <5% unmet demand.
- **Crime Response Layer**: Applied XGBoost + Random Forest for spatial crime risk scoring combined with Mixed-Integer Linear Programming (MILP via `scipy.optimize / HiGHS`) for patrol allocation, achieving **88.6% accuracy** and **92.1% spatial coverage**.
